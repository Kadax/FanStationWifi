# FanStationWifi

ESP8266 проект для интеллектуального управления вентиляционной системой с веб-интерфейсом

## Описание проекта

FanStationWifi - это система управления вентилятором, разработанная на базе микроконтроллера ESP8266. Система обеспечивает удаленное управление через Wi-Fi с возможностью обновления прошивки через OTA, а также включает LED-индикацию состояния и физические переключатели.

## Функциональные возможности

- **Wi-Fi управление**: Подключение к сети с веб-интерфейсом для управления
- **OTA обновление**: Безопасное обновление прошивки через Wi-Fi
- **Web API**: REST API для программного управления
- **LED индикация**: Визуализация статуса системы и настроек
- **Аналоговые переключатели**: Позволяют управлять режимами вручную
- **EEPROM сохранение**: Сохранение настроек скорости вентилятора при перезагрузке
- **Многоскоростной режим**: 15 уровней мощности вентилятора

## Физические компоненты

- **Микроконтроллер**: ESP8266 (ESP-12E)
- **LED-лента**: WS2811, 20 светодиодов
- **Сервоприводы**: 3 сервопривода для управления заслонками и направлением потока
- **Управляющие кнопки**: Аналоговые переключатели для ручного управления
- **Модули**: DHT22 для мониторинга температуры (при необходимости)

## Технические характеристики

- **Низковольтный порт**: 5V
- **Высоковольтный порт**: 12V
- **Мощность вентилятора**: до 50W
- **Wi-Fi**: 2.4GHz, 802.11 b/g/n
- **Память**: EEPROM 512 bytes для сохранения настроек

## Установка и подключение

### Необходимое оборудование
- ESP8266 модуль (ESP-12E)
- LED-лента WS2811
- 3 сервопривода
- Аналоговые переключатели
- Модуль реле для высокого напряжения

## Настройка

### Конфигурация Wi-Fi и OTA

1. Скопируйте `config_example.h` в `config.h`
2. Отредактируйте файл с вашими настройками:
   - `WIFI_SSID`: Имя вашей сети
   - `WIFI_PASSWORD`: Пароль Wi-Fi
   - `OTA_HOSTNAME`: Имя устройства в сети
   - `OTA_PASSWORD`: Пароль для OTA обновления

## Web API

Система предоставляет REST API для программного управления:

| Endpoint | Method | Описание | Параметры |
|----------|--------|----------|-----------|
| `/api/status` | GET | Получить текущий статус | Нет |
| `/api/power` | GET | Получить состояние питания | Нет |
| `/api/power/set` | GET | Включить/выключить вентилятор | `value` (1 или 0) |
| `/api/speed` | GET | Получить текущую скорость | Нет |
| `/api/speed/set` | GET | Установить скорость вентилятора | `value` (1-15) |
| `/api/direction` | GET | Получить направление потока | Нет |
| `/api/direction/set` | GET | Установить направление потока | `value` (1 или 0) |
| `/api/servo` | GET | Получить положение сервопривода | Нет |
| `/api/servo/set` | GET | Установить положение сервопривода | `value` (1 или 0) |

### Пример запросов

```bash
# Получить статус
curl http://192.168.1.100/api/status

# Включить вентилятор
curl "http://192.168.1.100/api/power/set?value=1"

# Установить скорость 8
curl "http://192.168.1.100/api/speed/set?value=8"

# Установить направление потока
curl "http://192.168.1.100/api/direction/set?value=1"
```

## Использование переключателей

Система поддерживает физические переключатели для ручного управления:

| Кнопка | Функция |
|--------|----------|
| Кнопка 1 | Включить/выключить вентилятор |
| Кнопка 2 | Сменить направление потока воздуха |
| Кнопка 3 | Переключить положение сервопривода заслонки |
| Кнопка 4 | Уменьшить скорость на один уровень |
| Кнопка 5 | Увеличить скорость на один уровень |

## LED индикация

LED-лента отображает состояние системы:

- **Синий цвет**: Индикатор работы
- **Красный цвет**: Индикатор ошибок или отсутствия питания
- **Зеленый цвет**: Индикатор активного направления потока
- **Интенсивность**: Отражает текущую скорость вентилятора (зеленая зона)

Состояния индикации:
- Последние 5 светодиодов: статусы системы
- Остальные светодиоды: визуализация мощности вентилятора

## Особенности реализации

- **Автономный режим**: Работа без Wi-Fi при невозможности подключения к сети
- **Мягкий старт**: Плавное увеличение скорости вентилятора
- **Защита от дребезга**: Дебаунс кнопок для надежной работы
- **Стабильность**: EEPROM сохранение настроек для восстановления состояния при перезагрузке

## Интеграция с системой управления

Проект FanStationWifi может быть интегрирован с системой управления FanWorker, которая работает на базе .NET 10 и использует PostgreSQL БД для хранения статистики и управления.
