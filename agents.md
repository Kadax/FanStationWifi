# Архитектура

## Проект прошивки микроконтроллера
- расположен в папке Fans
- создан для ESP8266
- обновление по WIFi

## Проект схемы БД
- раположен в папке FanWorker\FanModelDB
- используется .net 10 и EntityFramework
- в качестве БД используется PostgreSQL

## Worker по управлению 
- раположен в папке FanWorker\FanWorker
- используется .net 10
