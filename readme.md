# FanStationWifi

Проект управления станцией вентиляции на Arduino: регулировка скорости вентилятора, переключение направления потока воздуха, управление servo-заслонками и индикация состояния на светодиодной ленте.

## Возможности

- **Регулировка скорости вращения вентилятора** — 15 уровней (PWM на выводе D7)
- **Переключение направления потока** — два режима через транзисторные выходы (D5, D6)
- **Управление servo-заслонками** — верхняя и нижняя заслонка, а также servo-мотор переключения
- **Индикация состояния** — светодиодная лента WS2811 (20 диодов): шкала скорости + 5 диодов состояния (питание, направление, заслонки)
- **Сохранение скорости** — последний выбранный уровень скорости хранится в EEPROM и восстанавливается при включении
- **Управление с кнопки** — аналоговая матрица кнопок с дребезгом (5 кнопок)
- **Обновление прошивки по Wi-Fi (OTA)** — загрузка новой прошивки по сети без перепрошивания по USB

## Схема подключения

| Вывод | Назначение |
|-------|------------|
| D0 (`button_s`) | Резервный вывод кнопки |
| D1 (`ServoTop_PIN`) | Servo верхней заслонки |
| D2 (`ServoBottom_PIN`) | Servo нижней заслонки |
| D3 (`ServoMotors_PIN`) | Servo переключателя потока |
| D5 (`Switch1`) | Управление направлением (транзистор) |
| D6 (`Switch2`) | Управление направлением (транзистор) |
| D7 (`motors_PIN`) | Питание вентиляторов (PWM) |
| D8 (`LED_PIN`) | Светодиодная лента WS2811 |
| A0 (`buttons`) | Аналоговый вход матрицы кнопок |

## Кнопки

| Клавиша | Действие |
|---------|----------|
| 1 | Вкл/выкл вентилятора |
| 2 | Смена направления потока |
| 3 | Переключение заслонки |
| 4 | Уменьшение скорости |
| 5 | Увеличение скорости |

## Библиотеки

- **FastLED** — управление светодиодной лентой
- **Servo** — управление сервоприводами
- **EEPROM** — сохранение настроек
- **WiFi (ESP8266WiFi)** — подключение к сети
- **ArduinoOTA** — приём новой прошивки по Wi-Fi

## Структура кода

| Функция | Назначение |
|---------|------------|
| `setup()` | Инициализация выводов, чтение скорости из EEPROM |
| `loop()` | Обработка кнопок, индикация, управление направлением |
| `SetSpeedMotors()` | Установить скорость вращения (PWM) |
| `SetServoPosition()` | Поставить сервы заслонок в нужную позицию |
| `UpdateKeyValue()` | Реакция на нажатия кнопок |
| `GetKeyValue()` | Дребезг (debounce) при чтении кнопки |
| `GetButtonNumberByValue()` | Определение номера кнопки по аналоговому значению |
| `SetDirection()` | Установить направление потока / отключить вентиляторы |
| `ShowLedState()` | Индикация текущего состояния на ленте |

## Обновление прошивки по Wi-Fi (OTA)

Проект поддерживает обновление прошивки по сети через `ArduinoOTA`.

### Настройка

Параметры Wi-Fi и OTA задаются в файле `Fans/config.h`:

```cpp
#define WIFI_SSID     "YOUR_WIFI_SSID"
#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"

#define OTA_HOSTNAME "fanstation"   // имя устройства в сети
#define OTA_PASSWORD "1234"         // пароль защиты OTA (пустая строка = без пароля)
```

После изменения конфига перепрошьте устройство один раз по USB.

### Как обновить

В Arduino IDE:

1. Установите библиотеки **ArduinoOTA** и **ESP8266WiFi** (через Диспетчер библиотек) или убедитесь, что они доступны.
2. В меню **Sketch → «OTA: ...»** будет виден пункт с именем `fanstation` (как задано в `OTA_HOSTNAME`).
3. Выберите эту строку вместо USB-порта и нажмите **Upload (Нагрузить)**.
4. Введите пароль (если задан в `OTA_PASSWORD`) и дождитесь завершения загрузки.

Устройства также обнаруживается утилитой **Arduino CLI**:

```bash
arduino-cli device list
# найдётся "fanstation" (IP устройства)
arduino-cli upload -p fanstation -b esp8266:nodemcuv2 --fqbn esp8266:nodemcuv2:FlashSize=4M Fans
```

### Поведение

- При старте устройство подключается к Wi-Fi (~15 сек таймаут) и регистрирует OTA-сервер.
- В `loop()` в самом верху вызывается `ArduinoOTA.handle()` — это требование библиотеки, не пропускайте.
- Если Wi-Fi недоступен, устройство работает автономно (кнопки, сервы, светодиоды).

---

## Замечания

- Индикация скорости: 15 светодиодов загораются красным/жёлтым в зависимости от уровня (0..15), при выключенном вентиляторе — тускло-фиолетовые.
- Позиции servo: `minValue = 35` (заслонка закрыта) и `270`/`180` (открыта).
- **Важно**: для загрузки прошивки по Wi-Fi нужен **ESP8266 (NodeMCU)** или совместимая плата. Для AVR-плат (Nano/UNO) OTA не работает.
